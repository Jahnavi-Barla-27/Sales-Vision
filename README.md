# Sales Vision — Sales Prediction & Analytics System

## 📌 Project Overview

Sales Vision is a Machine Learning-based sales prediction and analytics system developed using Python and Streamlit.

The system uses historical sales data to predict sales based on:

- Quantity
- Discount
- Shipping Cost
- Year

It also provides interactive sales analytics and visualizations to help understand sales patterns.

## 🤖 Machine Learning Models

The project uses and compares:

- Linear Regression
- Random Forest Regressor

Models are evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 📊 Analytics

The application provides:

- Sales by Region
- Sales by Year
- Sales by Category
- Model Comparison
- Feature Importance
- Previous vs Current Prediction Comparison

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Plotly
